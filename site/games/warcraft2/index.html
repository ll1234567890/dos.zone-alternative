Warcraft II: Tides of Darkness

Blizzard, 1995 · Real-time strategy · Up to 8 players over IPX

1 Load your game files

This site does not host Warcraft II. Use your own copy of the DOS version, which is the folder that contains WAR2.EXE.

Drop the game folder or a .zip here
or pick it:

Optional: put a CD image (.cue/.bin or .iso) in the same folder or zip. It is mounted as drive D: for CD music and cutscenes.

2 Choose how to play

Single player

Campaigns, custom scenarios and skirmish against the computer.

Host an online game

You get a room code and a link to send to friends. Start the game first, then they join.

Join a friend

Paste the room code or link your host sent you.

Playing online

Every player needs their own copy of the game, ideally the same version.

Host

  1. Click Host room and copy the link from the bar above the game.
  2. In Warcraft II, choose Multi Player Game, then IPX Network.
  3. Enter your name and click Create Game, then wait in the lobby.

Everyone else

  1. Open the link (or paste the code) and click Join.
  2. Wait for "connected", then choose Multi Player Game, then IPX Network.
  3. Pick the host's game from the list and join.

Tips

  • If the mouse feels off, turn on mouse lock in the js-dos sidebar settings. Press Esc to release it.
  • Saved games and settings are stored in this browser when you click Leave or switch tabs.
  • Players connect through the DOS Harbor relay server. If it was idle, the first connection can take up to a minute.
  • The js-dos sidebar has fullscreen, speed and keyboard tools.
  • No music? In Warcraft II's sound options, turn CD audio off and the music volume up. If you changed the sound card in SETUP, use Reset game settings.
