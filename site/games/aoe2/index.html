Age of Empires II: The Age of Kings

Ensemble Studios / Microsoft, 1999 · Real-time strategy · Windows 95/98

1 Load your Windows disk image

This is a Windows game, so it runs inside an emulated Windows 95/98 PC (DOSBox-X). This site does not host Windows or the game. Load your own hard-disk image with Windows and Age of Empires II installed.

Drop your disk image here
.qcow2, .img or .vhd, a .zip of it, or a ready .jsdos bundle

Pick several files at once to add a second disk (D:) or the game CD (.iso, or .cue + .bin). The largest disk image boots as C:.

2 Play

Single player

Campaigns, random maps and scenarios against the computer.

Good to know

  • The whole disk image is loaded into browser memory. Keep it small: a .qcow2 image or a lean Windows install of a few hundred MB works best. Desktop Chrome or Edge recommended.
  • Windows changes your disk as you play, so the browser stores a changed copy of the whole image. Shut Windows down (Start → Shut Down) before clicking Leave; that is when your progress is saved.
  • Saving a large image takes a while; wait for Leave to finish.
  • If you install the game from CD, keep the CD image loaded: many Windows games check for their CD.
  • Online multiplayer isn't available for Windows games yet.
  • The js-dos sidebar has fullscreen, keyboard and speed tools.
