Tips

  • The program list is sorted by best guess. If the game doesn't start, try another program, or the game's .BAT file.
  • For a .jsdos bundle, "Keep the bundle's startup" runs its own [autoexec].
  • Running slow? Lower the CPU speed. The game feels sluggish? Raise it. Check the % under TURBO in the js-dos sidebar: it should stay at 100%.
  • No sound? Run the game's SETUP or INSTALL program once (pick it as the program), choose the sound card set above (port 220, IRQ 7, DMA 1), then switch back.
  • Folder and file names longer than 8 characters are shortened to DOS names (for example MYGAME~1).
  • Online play: both players load the same game, one hosts, the other joins with the code. In the game, pick its IPX network option.
  • Progress saves when you click Leave or switch tabs.
